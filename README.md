# Сложно сосредоточиться

Адаптивная страница о концентрации внимания. Поддерживает светлую, тёмную и автоматическую темы; выбор сохраняется в браузере.

Репозиторий: https://github.com/meloch287/slozhno-sosredotochitsya-ad

Откройте `index.html` в браузере или запустите локальный сервер из папки проекта:

```sh
python3 -m http.server 8044 --bind 127.0.0.1
```

Страница будет доступна по адресу http://127.0.0.1:8044.

Проверены макеты 375, 768 и 1024 px, промежуточные ширины, шесть сочетаний системной и выбранной темы, сохранение выбора и клавиатурный фокус. HTML прошёл проверку Nu Html Checker без замечаний. Автотесты Практикума запускаются в GitHub Actions при отправке коммитов.
